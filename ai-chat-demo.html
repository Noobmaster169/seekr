🤖 AI Chat Assistant Demo

🚀 How to Use the AI Chat

Step 1: Press Alt + L to open the AI Chat overlay

Step 2: Go to the Settings tab and configure your API key

Step 3: Start chatting with the AI assistant!

The overlay will appear on top of this page and any other website you visit.

✨ Features

🎯 Smart Conversations

Chat with advanced AI models like GPT-3.5 and GPT-4 for intelligent responses.

🌐 Universal Overlay

Works on any website - drag and position the chat wherever you need it.

💾 Message History

Your conversations are saved locally and persist across sessions.

🎨 Beautiful UI

Glassmorphism design with smooth animations and modern interface.

⚡ Real-time Streaming

See AI responses as they're generated with streaming support.

🔒 Privacy First

Your API keys and conversations are stored locally in your browser.

🛠️ Configuration

The AI Chat supports multiple providers:

  • OpenAI - GPT-3.5, GPT-4, and other models
  • Anthropic - Claude models (coming soon)
  • Custom APIs - Use your own AI endpoints

To get started, you'll need an API key from your chosen provider. The most popular option is OpenAI, which you can get from platform.openai.com.

🎮 Keyboard Shortcuts

Toggle the AI Chat overlay visibility

📱 Technical Details

This AI Chat Assistant is built with:

  • React 18 - Modern UI framework
  • Framer Motion - Smooth animations
  • TailwindCSS - Utility-first styling
  • OpenAI SDK - AI model integration
  • Marked - Markdown rendering
  • DOMPurify - Safe HTML sanitization
